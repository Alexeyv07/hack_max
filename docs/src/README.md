# Альтернативная документация «КасаетсяМеня»

Эта версия документации построена вокруг всех 56 экранов из переданного PDF: бота, группового чата и мини-приложения. Красные стрелки на скриншотах показывают, куда нажимать. Персональные данные и уникальные пригласительные ссылки на скриншотах скрыты.

Документация охватывает весь пользовательский путь: первый запуск, четыре способа выбора адреса, подключение домового чата, работу администратора, управление адресами, новости, карту и уведомления.

Начните с [первого запуска](overview.md), а затем переходите к нужному сценарию через `SUMMARY.md`.

# Управление адресами

На главной экрана бота кнопка **«Управлять адресами»** открывает список домов,
которые вы указали для себя.

## Что можно сделать

- посмотреть сохранённые адреса;
- удалить адрес из *личного* списка.

Удаление адреса из вашего списка **не отключает** домовой чат и не убирает
адрес у всей группы соседей. Чтобы убрать адрес именно у чата, это делает
администратор группы (кнопка в приветственном сообщении бота в чате).

## Если адреса ещё нет

Вернитесь на главную (`/home`) или нажмите «Указать свой адрес» и выберите дом
одним из способов: список, индекс, карта или текст.

Подробнее про подключение дома и чата: [Подключение чата](./chat-link.md).

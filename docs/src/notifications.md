# Личные уведомления

Важные события рядом с домом приходят **личным сообщением** от бота
(красный маркер 🔴).

## Как это выглядит

1. Бот присылает короткое сообщение: **заголовок** события.
2. Подробный текст по умолчанию **скрыт**. Нажмите **«Подробнее»**, чтобы раскрыть,
   и **«Свернуть»**, чтобы снова спрятать (в MAX нет встроенных spoiler-тегов —
   раскрытие сделано через кнопку и правку того же сообщения).
3. Внизу кнопка **«Увидел»** — нажмите её, когда прочитали.
4. Пока кнопку не нажали, бот может напомнить снова через час.
   Старое такое же сообщение при этом убирается, чтобы чат не засорялся.

## Если уведомление не пришло

На хакатоне и для проверки можно запросить пример командой:

`/get_notify`

Бот покажет, как выглядит настоящее уведомление. Сообщение с командой
после этого удалится само.

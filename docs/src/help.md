# Помощь и обратная связь

На главной странице есть отдельная кнопка **«Помощь и обратная связь»**. Используйте её, если возник вопрос по работе сервиса или нужно сообщить о проблеме.

![Кнопка Помощь и обратная связь на главной](images/54-home-main.jpg)

В исходном наборе скриншотов показан только вход в этот раздел, поэтому дальнейшие экраны здесь не описаны.

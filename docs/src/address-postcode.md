# Выбор адреса по почтовому индексу

Если известен шестизначный индекс, этот способ позволяет быстро сузить список улиц и домов.

В меню выбора адреса нажмите **«Указать почтовый индекс»**.

![Выбор способа по индексу](images/10-picker-menu-postcode.jpg)

Бот попросит отправить индекс обычным сообщением. Индекс не выбирает дом автоматически - он только ограничивает список подходящих адресов.

![Запрос шестизначного индекса](images/07-postcode-prompt.jpg)

После отправки индекса появится список улиц, относящихся к нему. Выберите нужную улицу.

![Улицы по индексу](images/08-postcode-street.jpg)

Затем выберите дом. Если список большой, используйте навигацию по страницам снизу.

![Дома по выбранной улице](images/09-postcode-house.jpg)

После выбора дома дальнейший сценарий совпадает с другими способами: сервис показывает выбранный адрес и либо предлагает существующий чат, либо помогает подключить новый.

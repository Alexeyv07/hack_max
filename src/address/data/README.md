# Московский справочник для MVP

`moscow.jsonl.gz` — 125 562 уникальных адреса зданий в административных границах
Москвы, включая Новую Москву и Зеленоград. Это доступные данные OSM, не полный
официальный реестр всех домов.

| Результат подготовки | Записей |
| --- | ---: |
| Исходные объекты OSM | 132 448 |
| Адреса для загрузки | 125 562 |
| Индекс уже был в OSM | 19 970 |
| Индекс дополнен из локального ГАР | 81 641 |
| Всего с индексом | 101 611 |
| Без подтверждённого индекса | 23 951 |

У 2 873 повторяющихся адресов расходились координаты или другие поля:
все их 6 876 исходных записей сохранены в `rejected.jsonl.gz` и исключены из
импорта. Ещё 10 полностью одинаковых повторов объединены. Дом для одного
PK=address_text не выбирается случайно.

## Происхождение и ограничения

- Адрес и координаты: © OpenStreetMap contributors, [ODbL 1.0](https://www.openstreetmap.org/copyright).
  Снимок от 15.09.2026, запрос — `moscow.overpassql`, сервер —
  `https://maps.mail.ru/osm/tools/overpass/api/interpreter`.
- Дополнительные индексы: локальная база Gar77 от 26.05.2026, SDK Pullenti 4.34,
  [garfias.ru](https://garfias.ru). Бесплатное использование SDK/индекса ограничено
  некоммерческими задачами; для коммерческого применения нужна соответствующая лицензия.
  SDK и база Gar77 в репозиторий не включены.
- `source_keys` сохраняет идентификаторы OSM; `postcode_source` — источник индекса,
  `gar_guid` — найденный объект ГАР. Загрузчик оставляет в БД только поля модели;
  происхождение сохраняется в файле. Контрольные суммы и статистика — `manifest.json`.
- Существующие индексы OSM не заменяются. Пропуски заполняются только по точному
  совпадению нормализованной улицы, дома, корпуса и строения, при единственном
  подходящем ГАР-объекте в пределах 100 м. Это консервативное сопоставление,
  не гарантия отсутствия ошибок в источниках. Неподдерживаемые номера и
  неоднозначные совпадения оставлены без индекса.
- Для контура здания координаты — центр ограничивающего прямоугольника Overpass,
  не подъезд. Нежилые здания включены для геопоиска событий.
- `is_private=false` только для `building=apartments`; `true` — для `house`,
  `detached`, `semidetached_house`; остальные — `null`. Это теги OSM,
  не юридическая классификация и не разрешение подключать любой адрес как домовой чат.
- `postal_code=null` не мешает поиску по улице/дому и показу координат, но такой
  дом нельзя найти по индексу. Один индекс не обозначает единственный дом.

В интерфейсе карты сохраняйте атрибуцию OpenStreetMap. При распространении
справочника сохраняйте источники, условия ODbL и описание преобразований.

## Загрузка готового файла

Из корня проекта, с настроенной PostgreSQL:

```bash
alembic upgrade head
PYTHONPATH=src python -m address.seed src/address/data/moscow.jsonl.gz --validate-only
PYTHONPATH=src python -m address.seed src/address/data/moscow.jsonl.gz
```

Повторный импорт сохраняет `id`. Отсутствующие в новой выгрузке адреса автоматически
не удаляются: в дальнейшем на них могут ссылаться чаты.

## Воспроизведение подготовки

Скачивание выполняется только для обновления справочника, не при работе бота:

```bash
curl --fail --show-error --max-time 210 \
  --data-urlencode 'data@src/address/data/moscow.overpassql' \
  https://maps.mail.ru/osm/tools/overpass/api/interpreter -o /tmp/moscow-osm.json
PYTHONPATH=src:/путь/к/AddressPython python -m address.prepare_osm \
  /tmp/moscow-osm.json --output /tmp/moscow-prepared --gar-index /путь/к/Gar77
```

Официальные архивы: [AddressPython.zip](https://www.garfias.ru/assets/docs/AddressPython.zip),
[Gar77.zip](https://www.garfias.ru/assets/docs/Gar77.zip). В `PYTHONPATH` указывается
каталог, содержащий пакет `pullenti`; `--gar-index` указывает каталог с `regions.xml`.
Без `--gar-index` подготовка работает только с OSM и не требует SDK.
Проверьте новый `manifest.json` и обновите статистику перед заменой файлов в проекте.

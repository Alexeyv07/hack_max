# Проект "Умный город"

## Contributing flow

Ваш флоу для работы с проектом:
1) Создать ветку от main, где делается 1 фича: ```git checkout -b your-feature-name``` 
2) Сделать коммиты с описанием того, что было сделано (можно в интерфейсе ide): ```git commit -m "описание изменений"```
3) Сделать push в вашу ветку (можно в интерфейсе ide): ```git push origin your-feature-name```
4) Создать pull request в main ветку (в интерфейсе github). И замерджите проект.
5) ПЕРЕКЛЮЧИТЬСЯ НА ВЕТКУ MAIN: ```git checkout main``` 
6) Обновить локальную ветку main: ```git pull origin main```

Важные моменты:
- Если изменяете файл, который будет изменять кто-то другой параллельно с вами, то надо предупредить остальных, и замерджить ветку как можно быстрее!
- Мерджить конфликты нужно в локальной ветке!
- Делаем внятные комиты с директивами: 
  - ```FEAT:``` - новая фича
  - ```FIX:``` - исправление бага
  - ```REFACTOR:``` - рефакторинг кода
  - ```DOCS:``` - изменения в документации
  - ```TEST:``` - добавление тестов
